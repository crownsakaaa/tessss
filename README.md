#  YAZUAR™ APPAREL CO. — Web E-Commerce Distro & Streetwear
> **Tugas Proyek Pemrograman Web / Kewirausahaan Sekolah**  
> *Desain clean, to-the-point, typography tegas ala brand clothing lokal, tanpa hero banner raksasa atau marketing klise AI slop.*

---

##  Konsep Toko
**YAZUAR™ APPAREL CO.** adalah web toko online brand apparel & distro streetwear lokal (kaos boxy heavyweight 20s, hoodie fleece 330gsm, tote bag kanvas 14oz, topi corduroy, dan daily goods).

- **Langsung ke Produk**: Begitu website dibuka, pengguna langsung disuguhkan etalase katalog produk, filter kategori, pencarian, dan keranjang belanja tanpa ada banner dekoratif besar yang menghalangi pandangan.
- **Bahasa Natural & Humanis**: Deskripsi produk, spesifikasi bahan distro, dan ulasan pelanggan ditulis dengan gaya santai dan realistis seperti pembeli asli di Indonesia.
- **100% Portabel**: Menggunakan HTML5, CSS3, dan Vanilla JavaScript ES6 tanpa framework berat. Cukup klik ganda file `index.html` dan web langsung berjalan di browser mana pun tanpa butuh koneksi internet atau instalasi Node.js.

---

##  Fitur-Fitur Utama untuk Penilaian Guru

1. **Katalog & Filter Cepat (Real-Time)**:
   - Pencarian instan (ketik "kaos", "hoodie", "topi" langsung memfilter otomatis).
   - Filter Kategori: `ALL ITEMS`, `T-SHIRTS`, `OUTERWEAR`, `ACCESSORIES`, `LIFESTYLE`.
   - Urutkan: Paling Banyak Terjual, Termurah, Termahal, Rating Tertinggi.
2. **Modal Detail & Varian Ukuran**:
   - Pilihan ukuran distro (S, M, L, XL, XXL) atau varian gilingan/warna.
   - Stepper jumlah barang (+/-), indikator sisa stok, spesifikasi bahan, dan ulasan pembeli asli.
3. **Cart Drawer Off-Canvas (Slide-in)**:
   - Pengatur jumlah item, hapus produk, dan kalkulasi subtotal instan.
   - **Free Shipping Progress Bar**: Otomatis menghitung sisa belanja untuk klaim Bebas Ongkir (min. Rp 150.000).
   - **Kupon Diskon**: Masukkan kode `DISKON10` (potongan 10%) atau `POTONGAN25` (potongan Rp 25.000).
4. **Formulir Checkout & Simulator Pembayaran**:
   - Pilihan kurir: JNE, SiCepat, GoSend.
   - Pilihan pembayaran: **QRIS Dinamis** (dengan timer mundur 15 menit & tombol demo bayar instan), **Virtual Account BCA**, dan **COD**.
5. **Bukti Transaksi / Struk Digital (Print PDF)**:
   - Menghasilkan nomor resi resmi dan status **LUNAS (PAID)**.
   - Tombol **Cetak Struk (PDF)** yang sudah diformat khusus untuk cetak kertas/file PDF.
6. **Penyimpanan Lokal (LocalStorage)**:
   - Keranjang dan wishlist tetap tersimpan walau browser di-refresh.

##  Cara Menjalankan
1. Buka folder ini di File Explorer.
2. Klik dua kali pada file **`index.html`**.
3. Selesai! Web langsung terbuka dan siap dipresentasikan.
